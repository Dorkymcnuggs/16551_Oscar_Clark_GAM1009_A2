# GAM1009-2026T2

\# Summary

&#x09;This is my first SHMUP game, controls are typical WASD for movement, left mouse for fire type 1, right mouse fire type 2, alt changes the shooting pattern. Open the MainMenu level as this is the most functional slice. There will be waves of enemies that will need to be defeated and the boss will spawn which you'll need to defeat to win the game. 
Additionally here are what each pickup does, Purple gives 1 life, Blue gives a shield, Red gives +20 health, Green gives +20 max health, Pale Pink gives overdrive mode increasing spread of shots.
