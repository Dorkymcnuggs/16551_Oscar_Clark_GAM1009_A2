# GAM1009-2026T2

\# Summary

&#x09;This is my first SHMUP game, controls are typical WASD for movement, left mouse for fire type 1, right mouse fire type 2, alt changes the shooting pattern. Open the FinalAssignment level as this is the most functional slice. There will be waves of enemies that will need to be defeated and the boss will spawn which you'll need to defeat to win the game



\# Notes

&#x09;I've changed the death sequence to also store the old actor as the ui would have a hissy fit when it was removed
